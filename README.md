# Nebula

Nebula — кроссплатформенный AI-помощник для проведения собеседований.

Программа слушает интервьюера и кандидата, распознаёт вопросы и ответы,
предлагает оценки по заранее заданным критериям и формирует итоговое резюме
собеседования.

Ключевой продуктовый принцип: **Nebula является системой поддержки решения,
а не автономным судьёй**. Оценки AI носят рекомендательный характер, а итоговое
решение всегда принимает и подтверждает интервьюер.

Согласованная концепция, архитектура и границы первой версии описаны в
[docs/product-concept.md](docs/product-concept.md).
